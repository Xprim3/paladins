# Blood Paladins - Final Dark Theme Branding

## ✅ Branding Complete

The website now features a **dark, dramatic theme** that perfectly matches the "Blood Paladins" identity.

## Color Palette - Dark Theme

### Primary Colors
- **Blood Red**: `#DC143C` (Crimson Red)
  - Used for: Headings, CTAs, important elements, hover states
- **Dark Blood Red**: `#8B0000` (Deep Red)
  - Used for: Gradients, darker variants
- **Paladin Gold**: `#FFD700` (Gold)
  - Used for: Accents, highlights, special information, links
- **Dark Gold**: `#B8860B` (Dark Goldenrod)
  - Used for: Darker gold variants

### Background Colors
- **Dark Background**: `#0A0A0A` (Near Black)
  - Main page background
- **Dark Surface**: `#1A1A1A` (Dark Gray)
  - Section backgrounds, cards, elevated elements
- **Dark Border**: `#2A2A2A` (Medium Gray)
  - Borders, dividers

### Text Colors
- **Light Text**: `#FFFFFF` (White)
  - Primary text on dark backgrounds
- **Muted Text**: `#B0B0B0` (Light Gray)
  - Secondary text, less important information
